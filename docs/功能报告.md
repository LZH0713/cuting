## Cuting 的定位与差异点

1. **开源 + 隐私优先**：OCR 走 Apple Vision 完全离线；截图数据不上传；
   翻译密钥只存本机；无遥测。同类中同为开源且功能对齐的极少。
2. **翻译引擎可插拔**：有道（官方接口，国内直连）、Google、DeepL、百度、
   任意 OpenAI 兼容接口（智谱/DeepSeek/Ollama）自选，结果可编辑后复制——
   同类产品的翻译多数为内置单一引擎或会员功能。
3. **跨显示器选区**：选区可从一块屏拖到另一块（各屏绘制自己的部分），
   截图从合成桌面裁剪；混合缩放（2x/1x）显示器下坐标依然正确。
4. **覆盖层常驻预热 + Esc 原生救援**：热键到覆盖层呈现 < 200 ms 无冷启动；
   页面异常时原生层仍能取消会话，桌面不会被卡死的覆盖层困住。
5. **长截图不限应用**：手动滚动 + 偏移匹配拼接，对禁止自动滚动的
   应用（权限受限页面、自绘界面）同样可用；自动滚动方案（对比 PixPin 等）
   在评估中。
6. **签名更新的授权保持**：用同一证书签名时，应用内更新不重置
   「屏幕录制」授权（配合 CI 证书签名）。

## 小结

Cuting 已覆盖"截图 → 标注 → 长截图 → OCR → 翻译 → 复制/保存"的完整链路：
v0.2.0 补齐了标注与长截图两块此前最大的功能差距，且标注带完整的撤销/重做、
可随复制/保存/OCR 一起导出。**离线 OCR + 可插拔翻译引擎 + 跨显示器选区 +
签名自动更新**的组合在同类免费产品中独一份；剩余差距（贴图、自动滚动、
录屏）属于增量功能，不涉及架构限制。
